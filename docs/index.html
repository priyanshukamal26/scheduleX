About the Project

University Course & Exam Scheduler — modelling courses as graph nodes with prerequisite dependencies as directed edges, using BFS-based topological ordering to generate clash-free timetables.

🔗

Conflict Resolution

Resolves scheduling conflicts using graph dependency analysis. Two courses taught by the same faculty, or taken by the same student, are guaranteed to never overlap.

📅

Optimized Timetable

Produces a compact, clash-free timetable for any sample dataset. Supports multi-session batching for large courses that exceed hall capacity.

📈

Graph Traversal Insight

Strengthens understanding of graph traversal in scheduling problems. Watch Kahn's BFS algorithm sort prerequisites into a valid exam sequence.

How It Works

Four steps to go from a list of courses to a clash-free exam schedule.

🟠

Model as Graph

Courses become nodes. Prerequisites become directed edges. Faculty & student overlaps form the clash matrix.

🔀

BFS / Kahn's Sort

Topological sort ensures every prerequisite exam is scheduled before the course that depends on it.

📅

Greedy Placement

Each course gets the earliest slot that respects the clash matrix, hall limits, and prerequisite ordering.

✅

Clash-Free Output

The result: a Day × Session grid where no student or faculty member has two exams at the same time.
